Fuente y criterios de medición

Fuente: 10-Reporte Solicitud Bodega TRANSDA.xlsx, hoja OCTUBRE. Se incluyen 1,587 solicitudes únicas; no se mezclan las hojas Detalle1 y Hoja1, que contienen otros datos y resúmenes.

El resultado de auditoría se toma de STATUS AUDITORIA y se mantiene separado del estado operativo. Completos ÷ solicitudes filtradas × 100. Pendientes documentales = incompletos + no están físicos. Rechazados no se suman como pendientes documentales.

Se alinearon 107 filas desde la fila 1491 donde faltaba la columna TipoSolicitud. Los nombres se agrupan ignorando mayúsculas, acentos y espacios repetidos; se conserva el nombre original en el detalle. No se infieren responsables de errores a partir del nombre del solicitante.

Esta versión contiene los datos del Excel cargado el 5 de noviembre de 2026. Cambiar el Excel original no actualiza automáticamente el sitio: debe generarse y publicarse una nueva versión.
